# 🎬 Movie Gallery

A simple and responsive Movie Gallery webpage created using **HTML and CSS Grid**.

## 📌 About

This project displays a collection of movies with their posters, titles, genres, release dates, and short descriptions.

## 🛠️ Technologies Used

- HTML5
- CSS3
- CSS Grid

## 🎥 Movies Included

- Amaran
- Premam
- Keedam

## ✨ Features

- Responsive movie card layout
- CSS Grid system
- Movie posters and details
- Dark-themed design
- Clean and simple UI
